📦 الجزء 1: التثبيت والإعداد على Windows

خطوات مفصلة لتثبيت كل ما تحتاجه على Windows 10/11:

الخطوة 1: تثبيت Node.js

Puppeteer يحتاج Node.js 20 أو أحدث:

  • انتقل إلى nodejs.org
  • حمل نسخة LTS (20.x أو 22.x)
  • شغّل الملف وشبّت Next حتى الانتهاء
  • أعد تشغيل الكمبيوتر (مهم!)
  • افتح Command Prompt واكتب: node --version
# يجب أن ترى إصدار مثل v20.11.0 node --version npm --version
الخطوة 2: تثبيت VS Code
  • انتقل إلى code.visualstudio.com
  • حمّل VS Code لـ Windows
  • ثبّته بالخطوات الافتراضية
  • أضف الإضافات التالية:
الإضافة الوصف
Arabic Language Pack دعم اللغة العربية في VS Code
ESLint فحص الأخطاء البرمجية
Prettier تنسيق الكود تلقائيًا
Code Runner تشغيل الكود بسرعة

لتثبيت إضافة: Ctrl+Shift+X → ابحث عن اسم الإضافة → Install

الخطوة 3: تثبيت Puppeteer

أنشئ مجلد جديد وافتحه في VS Code:

# في Terminal (Ctrl+`) # 1. إنشاء مجلد جديد mkdir schoolos-pdf cd schoolos-pdf # 2. إنشاء مشروع Node.js npm init -y # 3. تثبيت Puppeteer npm install puppeteer # ملاحظة: سيقوم بتحميل Chrome (~170MB)
💡 نصيحة: إذا كان الإنترنت بطيئًا، يمكنك استخدام:
npm install puppeteer --save-exact
الخطوة 4: إنشاء ملف الاختبار

أنشئ ملف test.js في المجلد:

const puppeteer = require('puppeteer'); (async () => { const browser = await puppeteer.launch(); const page = await browser.newPage(); await page.setContent(` <html dir="rtl" lang="ar"> <body> <h1>مرحبًا بالعالم!</h1> <p>هذا اختبار للطباعة العربية</p> </body> </html> `); await page.pdf({ path: 'test.pdf', format: 'A4' }); await browser.close(); console.log('✅ تم إنشاء PDF بنجاح!'); })();
الخطوة 5: تشغيل الاختبار

شغّل الكود من Terminal:

node test.js # يجب أن ترى: ✅ تم إنشاء PDF بنجاح!
⚠️ إذا واجهت مشكلة:
  • خطأ "Cannot find module": npm install مرة أخرى
  • خطأ في Chrome: npm install puppeteer --force
  • بطء التحميل: طبيعي - Chrome يُحمّل أول مرة (~170MB)

🔧 الجزء 2: الاستخدام الأساسي للغة العربية

كل ما تحتاجه لدعم كامل للعربية وRTL:

أولاً: إضافة الخطوط العربية

استخدم خطوط Google Fonts مثل Noto Sans Arabic أو Cairo أو Amiri:

const html = ` <html dir="rtl" lang="ar"> <head> <meta charset="UTF-8"> <style> @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic:wght@400;500;700&display=swap'); body { font-family: 'Noto Sans Arabic', sans-serif; direction: rtl; text-align: right; line-height: 1.6; } h1 { font-size: 24px; font-weight: 700; color: #1e293b; margin-bottom: 20px; } p { font-size: 16px; color: #334155; margin-bottom: 12px; } </style> </head> <body> <h1>عنوان المستند</h1> <p>هذا نص عربي باستخدام خط Noto Sans Arabic من Google Fonts.</p> </body> </html> `;
💡 خطوط عربية موصى بها:
  • Noto Sans Arabic: خط حديث وواضح، مناسب للمستندات
  • Cairo: خط عصري، مناسب للعناوين
  • Amiri: خط كلاسيكي، مناسب للمستندات الرسمية
  • Tajawal: خط متوازن، مناسب للنصوص الطويلة
ثانياً: تنسيق RTL الكامل

استخدم dir="rtl" و text-align: right في كل مكان:

  • dir="rtl" على <html> أو <body>
  • text-align: right في CSS
  • direction: rtl في CSS
  • اختبر مع أرقام وإنجليزية للتأكد من Bidi
<html dir="rtl" lang="ar"> <style> body { direction: rtl; text-align: right; } .container { direction: rtl; } .bidi-test { /* هذا نص عربي مع أرقام 123 و English */ } </style> <body> <div class="container"> <p>هذا نص عربي مع رقم 123 وكلمة English</p> </div> </body> </html>
ثالثاً: إعدادات الطباعة الاحترافية

استخدم @media print للتحكم في الطباعة:

<style> /* CSS الأساسي */ body { font-family: 'Noto Sans Arabic'; padding: 20px; } .header { background: #0f766e; color: white; padding: 20px; } /* CSS للطباعة فقط */ @media print { body { padding: 0; margin: 0; } .no-print { display: none !important; } .header { background: #0f766e !important; -webkit-print-color-adjust: exact; print-color-adjust: exact; } a { text-decoration: none; color: #000; } @page { margin: 2cm; size: A4; } } </style>
رابعاً: خيارات PDF المتقدمة

كل خيارات page.pdf() المهمة:

await page.pdf({ path: 'output.pdf', format: 'A4', // A4, A3, Letter, etc. width: '210mm', // أو حجم مخصص height: '297mm', // أو حجم مخصص printBackground: true, // طباعة الخلفيات والألوان displayHeaderFooter: true, // إظهار الرأس والتذييل headerTemplate: `<div style="font-size:10px;text-align:center;width:100%">رأس الصفحة</div>`, footerTemplate: `<div style="font-size:10px;text-align:center;width:100%">صفحة <span class="pageNumber"></span> من <span class="totalPages"></span></div>`, margin: { top: '20mm', bottom: '20mm', left: '20mm', right: '20mm' }, landscape: false, // true للطباعة الأفقية preferCSSPageSize: true, // احترام CSS @page omitBackground: false, // false للحفاظ على الخلفيات scale: 1, // 0.5-2.0 للتكبير/التصغير });

🐛 الجزء 4: حل المشاكل الشائعة

أهم المشاكل التي تواجه المستخدمين مع العربية وحلولها:

⚠️ السبب:
  • عدم استخدام خط عربي يدعم الربط [web:122]
  • مشكلة في encoding (UTF-8)
  • استخدام خطوط لا تدعم Arabic Shaping
✅ الحل:
<html dir="rtl" lang="ar"> <head> <meta charset="UTF-8"> <!-- مهم جداً! --> <style> @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic&display=swap'); body { font-family: 'Noto Sans Arabic', sans-serif; <!-- خط يدعم الربط --> } </style> </head> ... </html>
خطوط موصى بها: Noto Sans Arabic, Cairo, Amiri, Tajawal

⚠️ السبب:
  • عدم استخدام dir="rtl" [web:132]
  • عدم استخدام text-align: right
✅ الحل:
<html dir="rtl" lang="ar"> <!-- على مستوى html --> <style> body { direction: rtl; <!-- مهم --> text-align: right; <!-- مهم --> } </style> <body> <div dir="rtl">...</div> <!-- أو على مستوى العنصر --> </body> </html>

⚠️ السبب:
  • الخط غير محمّل بشكل صحيح [web:134]
  • مشكلة في подключения الإنترنت
  • استخدام local fonts بدون embed
✅ الحل:
await page.setContent(html, { waitUntil: 'networkidle', <!-- انتظار تحميل كل الموارد --> encoding: 'utf-8' <!-- UTF-8 encoding --> }); // أو تحميل الخطوط يدويًا await page.addStyleTag({ content: ` @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic&display=swap'); ` });

⚠️ السبب:
  • Chrome يحتاج وقت للإقلاع أول مرة (~170MB)
  • تحميل الخطوط من الإنترنت
  • مشكلة في internet connection
✅ الحلول:
// 1. استخدام headless فقط (أسرع) const browser = await puppeteer.launch({ headless: true, args: [ '--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage', '--disable-accelerated-2d-canvas', '--disable-gpu' ] }); // 2. استخدام Browser Cache (أول مرة فقط بطيئة) // 3. تحميل الخطوط محليًا إذا كان الإنترنت بطيئًا

⚠️ السبب:
  • مشكلة في Bidirectional Text [web:122]
  • عدم استخدام Unicode بشكل صحيح
✅ الحل:
// هذا طبيعي - Bidi يعمل بشكل صحيح <p>هذا نص عربي مع رقم 123 وكلمة English</p> // سيظهر بشكل صحيح: "هذا نص عربي مع رقم 123 وكلمة English" // الاتجاه من اليمين لليسار، لكن الأرقام والإنجليزية من اليسار لليمين
ملاحظة: هذا سلوك صحيح لـ Bidi (Bidirectional Text).
💡 نصائح إضافية:
  • استخدم waitUntil: 'networkidle' دائماً [web:134]
  • تأكد من encoding: 'utf-8' في setContent
  • اختبر في Chrome أولاً قبل استخدام Puppeteer
  • استخدم DevTools في Chrome لفحص المشاكل
  • جرب الخطوط المختلفة (Noto, Cairo, Amiri, Tajawal)

✨ الجزء 5: أفضل الممارسات والنصائح

✅ يجب فعله (Do's)
  • استخدم دائمًا dir="rtl" و lang="ar" [web:122]
  • استخدم خطوط Google Fonts (Noto, Cairo, Amiri) [web:119][web:122]
  • استخدم waitUntil: 'networkidle' [web:134]
  • استخدم printBackground: true للألوان
  • استخدم @media print للتحكم في الطباعة
  • اختبر في Chrome أولاً قبل Puppeteer
  • وضع الهوامش razonables (20mm تقريبًا)
  • استخدم headless للإنتاج (أسرع)
❌ يجب تجنبه (Don'ts)
  • لا تستخدم خطوط محلية بدون embed
  • لا تنسى meta charset="UTF-8"
  • لا تستخدم waitUntil: 'load' فقط
  • لا تنسى await قبل العمليات
  • لا تستخدم headless: false للإنتاج (بطيء)
  • لا تعتمد على wkhtmltopdf (متوقف) [web:139]
  • لا تنسى إغلاق المتصفح (browser.close())
  • لا تستخدم CSS معقد جدًا (Flexbox جيد, Grid بحذر)
النصائح الأخيرة:
  • للأداء: استخدم headless, disable sandbox, cache fonts
  • للجودة: استخدم printBackground, CSS print media, linesreasonables
  • للصيانة: استخدم components, functions, data-driven templates
  • للنشر: استخدم Lambda مع chromium, أو Docker images
