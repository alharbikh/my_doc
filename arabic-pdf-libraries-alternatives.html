1) التحديات الرئيسية في الطباعة العربية

⚠️
المشكلة: معظم مكتبات PDF لا تدعم العربية بشكل صحيح بسبب:
  • RTL Text Direction: النصوص من اليمين لليسار تحتاج معالجة خاصة [web:120][web:122][web:127]
  • Arabic Shaping: الحروف العربية تتغير شكلها حسب موقعها [web:122]
  • Font Embedding: يجب تضمين الخطوط العربية في PDF [web:119][web:122]
  • Bidirectional Text: خلط العربية مع الإنجليزية/الأرقام [web:122][web:127]
❌ المشاكل الشائعة
  • النصوص تظهر مقطعة أو بالحروف المنفصلة [web:120]
  • الاتجاه من اليسار لليمين بدلاً من اليمين لليسار [web:120]
  • الخطوط لا تعمل بدون تضمين [web:119]
  • الأرقام والحروف الإنجليزية تختلط بشكل خاطئ [web:127]
  • بعض المكتبات لا تدعم العربية أصلاً [web:124]
✅ الحلول المطلوبة

🥇
Puppeteer + Playwright
أفضل جودة دعم كامل للعربية

Headless Browser يحول HTML إلى PDF باستخدام محرك Chrome/Chromium، مع دعم كامل للعربية وRTL [web:126][web:132][web:134].

  • ✅ دعم كامل للعربية: Chrome يدعم العربية بشكل أصلي [web:122][web:134]
  • ✅ RTL Direction: dir="rtl" يعمل بشكل طبيعي [web:132]
  • ✅ Arabic Shaping: معالجة تلقائية [web:122]
  • ✅ Font Embedding: تضمين خطوط Google Fonts [web:134]
  • ✅ CSS كامل: Flexbox, Grid, Print Media Queries [web:126]
  • ✅ أعلى جودة: نفس جودة المتصفح [web:126]
const puppeteer = require('puppeteer'); const browser = await puppeteer.launch(); const page = await browser.newPage(); await page.setContent(` <html dir="rtl"> <style> @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic'); body { font-family: 'Noto Sans Arabic'; } </style> <h1>مرحبا بالعالم</h1> </html> `, { waitUntil: 'networkidle' }); await page.pdf({ path: 'output.pdf', format: 'A4' });
التكلفة: مجاني

  • ✅ RTL مدمج: دعم تلقائي للعربية/الفارسية [web:123]
  • ✅ بدون إعداد: package standalone [web:123]
  • ✅ Client-side: يعمل في المتصفح [web:119]
  • ✅ Document model: أسهل من jsPDF [web:109]
  • ⚠️ التحديث: آخر إصدار 1.2.0 (4 ساعات مضت) [web:123]
import PDFDocument from '@digicole/pdfmake-rtl'; const docDefinition = { content: [ { text: 'مرحبا بالعالم', direction: 'rtl' }, { text: 'هذا نص عربي', style: 'arabic' } ], defaultStyle: { font: 'NotoSansArabic' } }; pdfMake.createPdf(docDefinition).download();

PrinceXML (Princexml)
جودة احترافية مدفوع

محرك HTML إلى PDF احترافي مع دعم كامل للعربية منذ 2007، وأعلى جودة طباعة [web:129][web:130][web:133][web:136].

  • ✅ دعم كامل للعربية: منذ Prince 7.0 [web:133]
  • ✅ RTL و Bidi: دعم متقدم [web:133]
  • ✅ OpenType Fonts: دعم كامل للخطوط العربية [web:133]
  • ✅ CSS Print: أفضل دعم لـ CSS [web:126]
  • ✅ جودة عالية: يستخدم في النشر الاحترافي [web:126]
  • ❌ مدفوع: $495-1495 [web:129]
prince --input=right-to-left.html \ --output=output.pdf /* Prince يدعم CSS العربي */ html { direction: rtl; prince-text-transform: arabic; }

4) دليل التطبيق العملي

خطوات تطبيق أفضل حل (Puppeteer) لدعم العربية [web:122][web:132][web:134]:

الخطوة 1: إعداد Puppeteer
npm install puppeteer # أو لـ Lambda npm install @sparticuz/chromium
الخطوة 2: إضافة الخطوط العربية

استخدم خطوط Google Fonts مثل Noto Sans Arabic أو Amiri [web:119][web:122]:

/* في HTML */ <style> @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic:wght@400;700'); body { font-family: 'Noto Sans Arabic', sans-serif; direction: rtl; } </style>
الخطوة 3: إنشاء HTML بالعربية
const html = ` <html dir="rtl" lang="ar"> <head> <meta charset="UTF-8"> <style> body { font-family: 'Noto Sans Arabic'; } .header { text-align: right; } @media print { .no-print { display: none; } } </style> </head> <body> <h1 class="header">قرار تشكيل لجنة</h1> <p>بناءً على احتياجات العمل...</p> </body> </html> `;
الخطوة 4: توليد PDF
const puppeteer = require('puppeteer'); const browser = await puppeteer.launch(); const page = await browser.newPage(); await page.setContent(html, { waitUntil: 'networkidle', encoding: 'utf-8' }); await page.pdf({ path: 'output.pdf', format: 'A4', printBackground: true, margin: { top: '20mm', bottom: '20mm', left: '20mm', right: '20mm' } }); await browser.close();
الخطوة 5: (اختياري) Lambda Deployment

لـ AWS Lambda، استخدم chromium و أضف الخطوط كـ Lambda Layer [web:134]:

const chromium = require('@sparticuz/chromium'); const puppeteer = require('puppeteer-core'); const fs = require('fs'); // Add fonts const fontFiles = fs.readdirSync('/opt/fonts'); for (let file of fontFiles) { await chromium.font(file); } const browser = await puppeteer.launch({ args: chromium.args, executablePath: await chromium.executablePath(), headless: chromium.headless });
💡 نصائح مهمة:
  • استخدم waitUntil: 'networkidle' لضمان تحميل الخطوط [web:134]
  • جرب printBackground: true للألوان والخلفيات [web:132]
  • أضف encoding: 'utf-8' لدعم كامل للعربية [web:134]
  • استخدم dir="rtl" و lang="ar" في HTML [web:122]
  • اختبر على أجهزة مختلفة للتأكد من عرض الخطوط [web:119]
