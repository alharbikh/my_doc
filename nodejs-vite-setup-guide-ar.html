تثبيت Node.js وتشغيل الموقع باستخدام Vite

دليل عملي لنظام Windows يبدأ من تنزيل Node.js، ثم تجهيز مجلد الموقع، وتثبيت Vite، وتشغيل خادم التطوير، واختبار نسخة الإنتاج.

الخطوات
1. تثبيت Node.js 2. التحقق من التثبيت 3. تجهيز مجلد الموقع 4. فتح المشروع 5. تثبيت Vite 6. إعداد package.json 7. تشغيل الموقع 8. التجربة من الجوال 9. بناء نسخة الإنتاج
1

تثبيت Node.js

افتح صفحة التنزيل الرسمية وثبّت إصدار LTS المخصص لنظام Windows.

فتح موقع Node.js الرسمي

أثناء التثبيت

  • اترك الخيارات الافتراضية كما هي.
  • تأكد من تثبيت npm مع Node.js.
  • تأكد من تفعيل إضافة Node.js إلى PATH.
  • أغلق PowerShell أو VS Code ثم افتحه من جديد بعد انتهاء التثبيت.
يفضّل تثبيت أحدث إصدار LTS. يجب أن يكون الإصدار متوافقًا مع متطلبات Vite الحديثة.
2

التحقق من نجاح التثبيت

افتح PowerShell أو Terminal داخل VS Code ثم نفّذ:

node --version
npm --version

إذا ظهرت أرقام للإصدارين، فقد تم التثبيت بنجاح.

مثال: ظهور قيمة تبدأ بـ v24 لـ Node.js وقيمة رقمية لـ npm.
إذا ظهرت رسالة أن الأمر غير معروف، أعد تشغيل الجهاز ثم جرّب مرة أخرى.
3

تجهيز مجلد الموقع

أنشئ مجلدًا مستقلًا للموقع، مثل:

C:\Users\khmob\Desktop\hudoori-smart-pro-website

فك ضغط ملفات الموقع داخله. يجب أن يكون ملف index.html داخل المجلد مباشرة.

hudoori-smart-pro-website/
├── index.html
├── features.html
├── assets/
├── en/
└── ...
4

فتح المشروع في VS Code

افتح PowerShell ثم نفّذ:

cd C:\Users\khmob\Desktop\hudoori-smart-pro-website
code .

أو افتح VS Code واختر File → Open Folder ثم اختر مجلد الموقع.

5

تهيئة المشروع وتثبيت Vite

من Terminal داخل VS Code نفّذ:

npm init -y
npm install --save-dev vite

سيتم إنشاء ملف package.json ومجلد node_modules.

6

إعداد ملف package.json

افتح ملف package.json واجعل قسم الأوامر بهذا الشكل:

{
  "name": "hudoori-smart-pro-website",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "dev": "vite --host",
    "build": "vite build",
    "preview": "vite preview --host"
  },
  "devDependencies": {
    "vite": "^8.0.0"
  }
}
إذا كتب npm رقمًا أحدث لإصدار Vite داخل الملف، اترك الرقم الذي أضافه npm.
7

تشغيل خادم التطوير

نفّذ:

npm run dev

سيظهر عنوان محلي قريب من:

Local:   http://localhost:5173/
Network: http://192.168.1.25:5173/

افتح العنوان المحلي في المتصفح:

http://localhost:5173

لإيقاف الخادم اضغط Ctrl + C.

8

تجربة الموقع من الجوال

  • اجعل الكمبيوتر والجوال على شبكة Wi‑Fi نفسها.
  • افتح في الجوال عنوان Network الذي ظهر في Terminal.
  • اسمح لـ Node.js بالعمل على الشبكات الخاصة عند ظهور Windows Firewall.
لا تستخدم الرقم الموجود في المثال؛ استخدم عنوان Network الظاهر على جهازك.
9

بناء واختبار نسخة الإنتاج

أنشئ نسخة النشر:

npm run build

سينشئ Vite مجلدًا باسم:

dist

ثم اختبر النسخة المبنية:

npm run preview

غالبًا ستفتح على:

http://localhost:4173
